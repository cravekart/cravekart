# QuickBite — Online Food Delivery System

Beginner-friendly frontend mini project using HTML, CSS and JavaScript.

## Features
- Food menu with categories
- Search food items
- Add to cart
- Increase/decrease quantity
- Automatic total calculation
- Demo checkout message
- Responsive design

## Open in VS Code
1. Extract the ZIP file.
2. Open VS Code.
3. Select **File → Open Folder** and choose `online-food-delivery`.
4. Open `index.html` in a browser, or install the Live Server extension and click **Go Live**.

This is a frontend demo only. It does not process real orders or payments.
